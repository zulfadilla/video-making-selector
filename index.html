How to write a script
  • Each line = one scene.
  • # Title → big title scene.
  • - item → list; items appear one by one. A line ending with : right before it becomes the list heading.
  • *word* → highlighted in the accent colour.
  • Short lines with a number (60%, $5,000, 33 million) → the number counts up with animation.
  • An empty line ends a list.
  • [image: logo, pop, left] → an image appears in the scene (see "Images in scenes" below).
  • A line with only an image → full image scene. - [image: icon] Item → icon replaces the list bullet.

Images in scenes

appear & move like text

Place the cursor in the script, then click + Insert on an image. You can edit the command directly in the script, e.g. [image: logo, bounce, right, large, float, 1s] — 1s = appear after 1 second.

3. Voiceover

Press 🎙 Record on each scene, read the text, then press ■ Stop. Scenes stretch to fit your voice. Silence at the start & end is trimmed automatically.

Background music is lowered automatically while there is a voice. The browser's built-in robot voice can't be recorded into a video file — for an AI voice, generate an MP3 on a text-to-speech site (e.g. ElevenLabs, CapCut) and use Voice file.

4. Style

Decoration "None" = solid colour. Text colour is chosen automatically.

Drag images to reorder them, or use the ‹ › buttons. Image 1 appears first.
